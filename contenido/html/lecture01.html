Data

To keep the countries comparable, national accounts come from a single source: the OECD Quarterly National Accounts (SDMX API, dataflow DSD_NAMAIN1@DF_QNA), seasonally adjusted, in national currency. Volumes are chain-linked (PRICE_BASE = LR); shares use current prices (PRICE_BASE = V).

1. Data

The country dimension of the SDMX key (REF_AREA) is built from names(countries), so adding or removing a country in that vector is enough to change what is downloaded. The request is split into batches of 10 countries to keep each URL short and each response manageable.

Code 
oecd_qna <- function(areas) {
  url <- paste0(
    "https://sdmx.oecd.org/public/rest/data/",
    "OECD.SDD.NAD,DSD_NAMAIN1@DF_QNA,1.1/",
    "Q.Y.", paste(areas, collapse = "+"), "...B1GQ+P31+P3+P51G.......",
    "?startPeriod=1947-Q1&format=csvfile"
  )
  read_csv(url, show_col_types = FALSE,
           col_types = cols(OBS_VALUE = col_double(), .default = col_character()))
}

batches <- split(names(countries), ceiling(seq_along(countries) / 10))
raw <- map_dfr(batches, oecd_qna)

keep <- tribble(
  ~TRANSACTION, ~SECTOR, ~var,
  "B1GQ", "S1",  "Y",
  "P3",   "S1M", "C",   # final consumption of households + NPISH
  "P3",   "S13", "G",
  "P51G", "S1",  "I"

qna_all <- raw |>
  inner_join(keep, by = c("TRANSACTION", "SECTOR"), relationship = "many-to-many") |>
  filter(UNIT_MEASURE == "XDC", PRICE_BASE %in% c("LR", "V"))

2. Terminology and dating recessions

The lecture explains that there’s no uniform dating rules to define what constitutes a recession and an expansion. For example, the UK’s technical definition (two consecutive quarters of negative growth) and the NBER committee’s judgment-based dating for the US. Whereas countries such as Costa Rica has no official dating committee, so here the technical rule is applied to all countries, which also lets us see how far it is from the NBER dates for the US.

Code 
real <- real |>
  group_by(iso) |>
  mutate(
    y = log(Y), c = log(C), i = log(I), g = log(G),
    neg = (y - lag(y)) < 0,
    # quarter t is in recession if (t, t+1) or (t-1, t) are both negative
    rec = (neg & lead(neg)) | (neg & lag(neg)),
    rec = replace_na(rec, FALSE)
  ) |> ungroup()

shade <- function(df) {
  df |> group_by(iso) |>
    mutate(run = cumsum(rec != lag(rec, default = FALSE))) |>
    filter(rec) |> group_by(iso, run) |>
    summarise(start = min(date), end = max(date) %m+% months(3), .groups = "drop")
}
rec_bands <- shade(real)

4. Isolating the cycle

The goal is \(y_t = y_t^{\text{trend}} + y_t^{\text{cycle}}\). Three methods from the lecture.

Method 1: growth rates

Method 2: linear detrending

Estimate \(y_t = \alpha + \beta t + \epsilon_t\) country by country; the cycle is

\(y_t^c = y_t - (\hat\alpha + \hat\beta t)\).

Method 3: the HP filter

The trend solves

\[ \min_{\{y_t^T\}} \sum_{t=1}^{T} \left(y_t - y_t^T\right)^2 + \lambda \sum_{t=2}^{T-1}\left[y_{t+1}^T - 2y_t^T + y_{t-1}^T\right]^2 , \]

whose first-order conditions give \(y^T = (I + \lambda D'D)^{-1}y\), with \(D\) the \((T-2)\times T\) second-difference matrix. \(\lambda = 1600\) for quarterly data.

The HP filter written from the closed form (a good check of the FOCs), then both detrending methods:

Code 
hp_filter <- function(y, lambda = 1600) {
  n <- length(y)
  D <- bandSparse(n - 2, n, k = 0:2,
                  diagonals = list(rep(1, n - 2), rep(-2, n - 2), rep(1, n - 2)))
  trend <- as.vector(solve(Diagonal(n) + lambda * crossprod(D), y))
  list(trend = trend, cycle = y - trend)
}

lin_detrend <- function(y) {
  t <- seq_along(y)
  y - fitted(lm(y ~ t))
}

real <- real |> group_by(iso) |>
  mutate(
    y_lin = 100 * lin_detrend(y),
    y_hpT = hp_filter(y)$trend,
    across(c(y, c, i), ~ 100 * hp_filter(.x)$cycle, .names = "{.col}_hp")
  ) |> ungroup()

# G is shorter in some countries: filter only its non-missing span
real <- real |> group_by(iso) |>
  mutate(g_hp = { out <- rep(NA_real_, n()); ok <- !is.na(g)
                  out[ok] <- 100 * hp_filter(g[ok])$cycle; out }) |>
  ungroup()

5. Business-cycle stylised facts

Volatility and co-movement of the HP cycle, in the format of slide 37 and King and Rebelo (1999, Table 1): standard deviation, standard deviation relative to output, first-order autocorrelation, and contemporaneous correlation with output.

Code 
bc_stats <- function(d) {
  vars <- c(Y = "y_hp", C = "c_hp", I = "i_hp", G = "g_hp")
  map_dfr(names(vars), function(v) {
    x <- d[[vars[v]]]; y <- d$y_hp; ok <- !is.na(x)
    tibble(var = v,
           sd = sd(x[ok]),
           rel_sd = sd(x[ok]) / sd(y[ok]),
           ac1 = cor(x[ok][-1], x[ok][-sum(ok)]),
           corr_Y = cor(x[ok], y[ok]))
  })
}

## 2. Terminology and dating recessions

The lecture explains that there's no uniform dating rules to define what constitutes a recession and an expansion. For example, the UK's *technical* definition (two consecutive quarters of negative growth) and the NBER committee's judgment-based dating for the US. Whereas countries such as Costa Rica has no official dating committee, so here the **technical rule is applied to all countries**, which also lets us see how far it is from the NBER dates for the US.

```{r}
#| label: recessions-r
real <- real |>
  group_by(iso) |>
  mutate(
    y = log(Y), c = log(C), i = log(I), g = log(G),
    neg = (y - lag(y)) < 0,
    # quarter t is in recession if (t, t+1) or (t-1, t) are both negative
    rec = (neg & lead(neg)) | (neg & lag(neg)),
    rec = replace_na(rec, FALSE)
  ) |> ungroup()

shade <- function(df) {
  df |> group_by(iso) |>
    mutate(run = cumsum(rec != lag(rec, default = FALSE))) |>
    filter(rec) |> group_by(iso, run) |>
    summarise(start = min(date), end = max(date) %m+% months(3), .groups = "drop")
}
rec_bands <- shade(real)
```

The goal is $y_t = y_t^{\text{trend}} + y_t^{\text{cycle}}$. Three methods from the lecture.

### Method 2: linear detrending

Estimate $y_t = \alpha + \beta t + \epsilon_t$ country by country; the cycle is

$y_t^c = y_t - (\hat\alpha + \hat\beta t)$.

### Method 3: the HP filter

The trend solves

$$
\min_{\{y_t^T\}} \sum_{t=1}^{T} \left(y_t - y_t^T\right)^2
+ \lambda \sum_{t=2}^{T-1}\left[y_{t+1}^T - 2y_t^T + y_{t-1}^T\right]^2 ,
$$

whose first-order conditions give $y^T = (I + \lambda D'D)^{-1}y$, with $D$ the
$(T-2)\times T$ second-difference matrix. $\lambda = 1600$ for quarterly data.

The HP filter written from the closed form (a good check of the FOCs), then both detrending
methods:

```{r}
#| label: filters-r
hp_filter <- function(y, lambda = 1600) {
  n <- length(y)
  D <- bandSparse(n - 2, n, k = 0:2,
                  diagonals = list(rep(1, n - 2), rep(-2, n - 2), rep(1, n - 2)))
  trend <- as.vector(solve(Diagonal(n) + lambda * crossprod(D), y))
  list(trend = trend, cycle = y - trend)
}

lin_detrend <- function(y) {
  t <- seq_along(y)
  y - fitted(lm(y ~ t))
}

real <- real |> group_by(iso) |>
  mutate(
    y_lin = 100 * lin_detrend(y),
    y_hpT = hp_filter(y)$trend,
    across(c(y, c, i), ~ 100 * hp_filter(.x)$cycle, .names = "{.col}_hp")
  ) |> ungroup()

# G is shorter in some countries: filter only its non-missing span
real <- real |> group_by(iso) |>
  mutate(g_hp = { out <- rep(NA_real_, n()); ok <- !is.na(g)
                  out[ok] <- 100 * hp_filter(g[ok])$cycle; out }) |>
  ungroup()
```

## 5. Business-cycle stylised facts

Volatility and co-movement of the HP cycle, in the format of slide 37 and King and Rebelo

```{r}
#| label: facts-r
bc_stats <- function(d) {
  vars <- c(Y = "y_hp", C = "c_hp", I = "i_hp", G = "g_hp")
  map_dfr(names(vars), function(v) {
    x <- d[[vars[v]]]; y <- d$y_hp; ok <- !is.na(x)
    tibble(var = v,
           sd = sd(x[ok]),
           rel_sd = sd(x[ok]) / sd(y[ok]),
           ac1 = cor(x[ok][-1], x[ok][-sum(ok)]),
           corr_Y = cor(x[ok], y[ok]))
  })
}
```

  $\sigma_C/\sigma_Y \geq 1$ (Aguiar and Gopinath, 2007; Neumeyer and Perri, 2005); check
  whether Costa Rica fits that pattern. Note our $C$ includes durables, which pushes the ratio
  up for every country relative to the slides.
* **Government consumption** is weakly correlated with output — it is not in the slide table,
  but it is a natural addition for a fiscal-monetary research agenda.
